# SIFI experimental project

This repository contains the final experimental task and analysis pipeline developed for a Master's internship project on the multisensory sound-induced flash illusion.

## Repository structure

- [`experimental_task/`](experimental_task/) contains the final PsychoPy experimental task.
- [`analyses/`](analyses/) contains the preprocessing and statistical analysis pipeline, diagnostics, tables, and figures.

Detailed installation and execution instructions are provided in the README file of each directory.

## Data

Participant-level experimental data are not included in this public repository. The `analyses/data/` directory is kept only to document the expected input structure of the analysis pipeline.

The repository includes selected derived results, figures, and statistical outputs produced during the project.

Do not add participant identity keys, consent forms, contact details, or identifying session notes to this repository.
